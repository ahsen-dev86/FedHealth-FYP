# Historical material

These files describe the earlier nine-class, fourteen-feature workflow and its
separate thalassemia investigation. They are retained for report evidence and
must not be run as the current training pipeline. Old dataset files also remain
at their original paths for provenance; active code uses only `Dataset/`.

Four-class replacements live in `Module 3 ML/` and `Module 4 FL/`.
Historical test files here are excluded from pytest collection.
