# FedHealth dataset — proof of real-world origin

This dataset is **not synthetic**. Every one of the 3,200 rows in `fedhealth_cbc_4class.csv` is a real patient's
Complete Blood Count, copied unchanged (aside from unit conversion and cleaning) from a published, citable public
dataset. No row was generated by a model, a formula, or a random-sampling method such as SMOTE or a GAN. Each row
can be traced back to its exact source file and line number in `fedhealth_cbc_4class_provenance.csv`.

## What "clinical" vs "assigned" labels means
- **Clinical diagnosis** (2,124 rows, 66%): the source dataset itself states the patient's diagnosis (from a
  doctor, a lab report, or a confirmed HbA2/HPLC test).
- **Assigned from lab values** (1,076 rows, 34%, all from two datasets): the source file had the CBC results but no
  diagnosis column, so a diagnosis was assigned using standard, published clinical thresholds (WHO hemoglobin
  cutoffs for anemia, the HbA2 ≥ 3.5% rule for beta-thalassemia trait, and normal reference ranges for "healthy").
  These are still real patients with real lab values; only the label was added by us, using textbook rules, not
  guessed.

This is disclosed row-by-row in the `label_basis` column of `fedhealth_cbc_4class_provenance.csv` (`clinical`,
`hba2_rule`, or `range_rule`), so any row's origin and labeling method can be checked individually.

## How to verify this yourself
1. Open `fedhealth_cbc_4class_provenance.csv` — every row has a `source` (which dataset) and `source_row` (the exact
   line in that dataset's original file).
2. Open any of the 5 links above — each is a public, citable dataset page (2 Kaggle, 1 GitHub-style Kaggle set, 2
   Mendeley Data, the latter with a DOI and CC BY 4.0 license).
3. Full construction methodology, cleaning steps, and known limitations are documented in
   `DATASET_README.md` / `FedHealth Dataset Construction.pdf` in this same folder.

## What we did NOT do
- No synthetic patients (no SMOTE, no GAN, no random generation).
- Classes were balanced only by **downsampling** real rows to 800 per class — never by inventing rows.
- The only computed values are (a) exact CBC arithmetic identities (e.g. MCH = Hb ÷ RBC × 10) used to recover a
  column a source didn't record, and (b) borrowing WBC/PLT/RDW/NEUTp values from the nearest *real* patient in the
  same non-leukemia population when a source never measured them — never invented numbers. Every such cell is
  flagged in the `imputed` column of the provenance file.
